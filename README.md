# Exploring-The-Non-Political-Factors-Behind-Young-Voter-Enthusiasm-A-Machine-Learning-Approach

## Overview
This repository contains the multimodal approach taken to figure out the non political factors which affect young voter's voting behaior. The dataset is separated and used on both MLP and Sentiment Analysis, and then the final accuracy is computed. SHAP, LIME, and Correlation Tests are done to figure out the influential factors. Moreover, LIME is applied on the clusters of individual voting behavior to figure out the common features.
